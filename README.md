# Forecasting-and-Inventory-Optimization-System
Forecasting and Inventory Optimization System
# AAI-501 Final Team Project

AI-Driven Retail Demand Forecasting and Inventory Optimization System.

## Dataset
M5 Forecasting - Accuracy.

Place these files in a `data/` folder beside the notebook:
- `calendar.csv`
- `sales_train_evaluation.csv`
- `sell_prices.csv`

The notebook can also attempt to download the open-access Zenodo mirror.

## Run
1. Open the notebook in Google Colab or Jupyter.
2. Run the dependency-install cell.
3. Run all cells from top to bottom.
4. Review the generated `outputs/` files.
5. Update the final interpretation with the actual metrics produced by your run.
